# 被试测试执行手册（Pilot Test Protocol）

> 目的：验证 [product-direction.md](product-direction.md) 的核心假设——陌生用户看完认知画像的第一反应。
> 这个结果决定社交匹配方向值不值得做。

## 一、被试招募

- **3-5 人**，完全不了解 Nous，之前没听你讲过这个项目
- 优先人文社科在校生 / 毕业五年内（目标用户画像），至少 1 人非目标用户做对照
- 招募话术保持模糊："帮我测一个 AI 聊天工具，大概 40 分钟"——**不要提前说"它会分析你/给你画像"**，否则第一反应被污染

## 二、准备

- 环境：线上版（你的部署地址）或本地 `cd web && npm run dev`；提前确认 API key 可用、跑通一遍完整流程
- 每人一份观察记录表（见第五节），提前打印或开好文档
- 征得同意后录音；明确告知对话数据会被分析、仅用于产品验证、可随时退出
- **多被试数据隔离**：CLI 流程用 `--subject <名字>`（data/subjects/ 机制已就绪）；web 流程每人测完导出 JSON 后清 localStorage

## 三、流程脚本（约 40 分钟）

1. **开场（2 min）**：只说"跟它聊就行，它会问你问题，怎么舒服怎么答"。不解释原理、不预告画像。模拟真实冷启动。
2. **访谈（15-20 min）**：被试与 Nous 对话。你坐在斜后方，不插话、不点头、不笑。记录：中途有没有走神/看手机/问"还要多久"（访谈转化率的信号）。
3. **生成画像**：等待时可以闲聊，但不聊 Nous。
4. **★ 关键观察段（5 min，全场最重要）**：把画像给被试自己读，**你全程闭嘴**。盯着他读到矛盾/盲区段落的瞬间：
   - 身体往前凑、放慢、重读、笑出声 → 记"凑近"
   - 沉默、快速划过、皱眉、身体后仰 → 记"后缩"
   - 原话逐字记（"卧槽还真是" vs "这什么玩意"）
5. **结构化提问（10 min）**：见第四节。
6. **收尾**：谢谢 + 问是否愿意之后再测一轮（复访意愿本身是数据）。

## 四、提问脚本（顺序不能乱：先开放，再具体，最后过关两问）

1. "看完整体什么感觉？"（开放，不引导）
2. 指着盲区/矛盾段："这一段呢？"——追问到能分类为止：
   - **准-共鸣**："对，而且我自己没意识到"
   - **这不是我**：解读偏了 → 追问"哪里偏了？它是从你哪句话推出来的？"（定位是证据问题还是解读过度）
   - **对但不适**："是这样，但看着不舒服" → 追问"如果换个说法你能接受吗？"（措辞问题）还是"不管怎么说都不想被说" （时机/边界问题）
3. **过关两问（核心判据）**：
   - "这份画像你愿意主动给朋友看吗？"（愿意=强信号；"可以但不会主动"=弱；拒绝=负）
   - "如果它能根据画像给你推荐'和你同频的人'，你想看看是谁吗？"
4. "整个过程哪一刻最想关掉？"（找流失点）

**铁律：全程不为模型辩护。** 被试说"不准"时只追问哪里不准，绝不解释"其实它的意思是……"。你在测产品，不是在说服人。

## 六、结果判读

- **≥3/5 主动想看同频推荐** → 方向成立，进入匹配机制设计 + Phase C 叙事按"认识自己→找同频的人"写
- **普遍"挺准的"但过关两问冷淡** → "承认≠想用"被证实，社交方向存疑；Nous 回到工具/求职展示定位，Phase C 按"行为层质检员"写
- **普遍"这不是我"且集中在解读过度** → 方向未证伪，先修建模（收紧 PROPORTIONAL INTERPRETATION），修完再测一轮
- 每人测完 **24 小时内**把记录表归档到 `research/pilot-results/`，别攒

## 七、注意（工程侧）

- 本 session 无 ANTHROPIC_API_KEY——测试当天用你自己的环境跑
- 别在被试面前清 localStorage（教训 #3），导出 JSON 确认保存后再清
- Vercel 60s 超时偶发：如果画像生成失败，当场重试一次即可，别慌
