# Nous Helper（Mac 菜单栏分身助手）

复制一条聊天消息 → 悬浮窗弹出分身建议（triage + 草稿 + 质检）→ 点「填入输入框」草稿自动粘进微信/钉钉的输入框。

## 构建与运行

```bash
cd mac/NousHelper && ./install.sh   # 构建 → 安装到 /Applications/NousHelper.app → 重启
```

首次安装或重编后：系统设置 → 隐私与安全性 → 辅助功能 → 「+」→ 应用程序 → NousHelper（旧条目先删）。

菜单栏出现 `N·` 即在运行。退出：菜单栏 N· → 退出。

已配置开机自启（LaunchAgents）：`com.nous.web`（dev server）/ `com.nous.helper` / `com.nous.feishu`，
日志在 `~/Library/Logs/nous/`。停用：`launchctl unload ~/Library/LaunchAgents/com.nous.<名字>.plist` 并删除该 plist。

## 使用

1. 确保分身服务在跑：本地 `cd web && npm run dev`（默认连 `http://localhost:3999`），或菜单栏 → 服务器地址… 填 Vercel 域名
2. 在微信/钉钉/任何地方，把对方发来的消息**连按两次 ⌘C**（同一段文字 2 秒内复制两次）——单次复制不会打扰你；微信/钉钉的新消息横幅则会自动触发，无需复制
3. 右上角弹出建议面板；可点关系 chips（同事/上级/在意的人…）重新判断，或复制时直接带前缀：`上级：这周末有空吗`
4. 点**「填入输入框」**：草稿自动粘贴到当前前台应用的输入框（面板不抢焦点）。首次使用会弹「辅助功能」授权（系统设置 → 隐私与安全性 → 辅助功能，勾选 NousHelper）
5. 「仅复制」把草稿放进剪贴板；「不回，关闭」按分身判断关闭

## 隐私边界

- 剪贴板内容只发往**你自己配置的**分身服务，别无去处
- 启发式过滤：含中文或空格、2–500 字才会分析——密码/token/代码路径这类内容不会被发送
- 菜单栏可随时「暂停监听」

## 已知边界（v1）

- 无跨消息上下文（每次复制独立分析）
- 「填入」是模拟 ⌘V，要求光标已在目标输入框里（复制完消息通常就是这个状态）
- 调试日志：`NSLog` 输出，前台跑 `./.build/debug/NousHelper` 可直接看
